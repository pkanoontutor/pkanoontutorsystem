{% comment %} Shared chunked-upload client. Include once per page that uploads sheet PDFs, then call PkUpload.uploadPdf(file, {csrf, onProgress, onStatus}). Why chunks rather than one request per file: a whole-file POST holds a gunicorn worker for the entire transfer, so a handful of concurrent uploads exhausts every slot, the server stops reading those sockets, and the browser's progress bar freezes partway with no error to show. Each chunk here is its own short request, so a worker is never tied up, a stalled chunk fails fast and retries on its own, and an interrupted file resumes from the offset the server reports instead of starting over. {% endcomment %}
